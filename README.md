# 손종국 · Portfolio

Live: https://sonjonggug.github.io/Portfolio/

채용 담당자가 소개 → 대표 프로젝트 → 경력 → 실제 제품 화면 순서로 읽을 수 있도록 구성한 정적 포트폴리오입니다. 프로젝트 전체 개요와 직접 담당한 업무를 구분했습니다.

## Run locally

Node.js 18 이상에서 설치 단계 없이 실행합니다.

```sh
npm run dev
npm run check
```

Preview: `http://127.0.0.1:4173/Portfolio/`. GitHub Pages는 `main`의 루트 파일을 그대로 제공합니다. 별도 빌드나 프레임워크 런타임은 없습니다.

## Files

- `index.html`: 콘텐츠, 구조, 이미지 및 링크
- `assets/css/portfolio.css`: 디자인, 반응형 레이아웃, 인쇄 스타일
- `assets/js/portfolio.js`: 모바일 메뉴, 이미지 갤러리, 인쇄 시 상세 업무 펼치기
- `scripts/check.mjs`: 로컬 이미지·앵커·갤러리 누락 검사

이미지 갤러리는 방향키와 Escape를 지원합니다. 브라우저 인쇄 / PDF 저장 시 상세 경력이 펼쳐지고, 종료 후 기존 상태로 돌아옵니다. 기존 vendor 자산은 보존하되 새 페이지에서는 불러오지 않습니다.

## Readability and content review · 2026-10-26

Notion 이력서와 경력 기간, 담당 범위, 프로젝트, 수치, 학력 및 기술 목록을 대조했습니다.

- CJ 푸드빌의 `가용성 99.9%`는 이력서에 없어 삭제하고, Control Plane 3중화·단일 장애 지점 제거로 설명했습니다. 네오넥스소프트의 99.9%는 이력서에 근거가 있어 유지했습니다.
- CJ 푸드빌 동시 요청 처리량 요약을 이력서의 `1.5배 이상`으로 맞췄습니다. 나머지 성과 수치도 이력서의 자기기술에 근거하며, 독립적인 성능 측정 자료까지 검증한 것은 아닙니다.
- 하나은행 문서 전처리, 사내 RAG 문서 업로드·삭제·재색인 및 Kibana 점검, U2-BIO 데이터 검증·API 명세, 도파민 사신 출석·인앱 구매, 책린지 기록 조회·삭제와 접근 제어를 보완했습니다.
- 이력서에 없는 프로젝트 기간은 추가하지 않았습니다. 대학의 `2027.02`가 졸업 예정인지 등 기간의 의미는 확인이 필요하며, `재학 중` 상태를 유지했습니다.
- 기존 README에 출처가 남아 있는 실제 앱 이미지, 샘플 데이터 안내, YouTube 영상 및 외부 링크를 보존했습니다. 채널 소유 여부는 이력서만으로 새롭게 확인할 수 없어 기존 출처 기록을 유지했습니다.

UI는 흰색·회색과 파란 강조색, 직선 구분선으로 정리했습니다. 본문은 데스크톱 17px, 모바일 16px이며 제목·담당 업무·상세 설명을 구분합니다. 회전, 사진 위 장식, 이미지 자르기, 장식성 그림자와 움직임을 제거했습니다. 책린지 7장은 가로 갤러리와 전체 화면 보기로 유지하며 인쇄 시 모두 펼쳐집니다. 프레임워크나 런타임 의존성은 추가하지 않았습니다.
